PatentScout – Prior-Art Search Agent

1. Project Overview

PatentScout is a web-based Prior-Art Search Agent designed to help users search for existing patents and identify potentially similar inventions.

The project provides a simple and user-friendly interface for searching patent-related information, viewing results, and analyzing similarity between inventions.

2. Project Objectives

- To simplify the process of prior-art searching.
- To help identify potentially similar existing patents.
- To display patent search results in an organized format.
- To provide similarity analysis for better understanding of search results.
- To connect users with external patent databases.

3. Technologies Used

- HTML5 – Structure of the website.
- CSS3 – Styling and user interface design.
- JavaScript – Functionality and interactive features.

4. Key Features

- User-friendly interface.
- Patent search functionality.
- Patent result cards.
- Similarity analysis.
- Similarity score visualization.
- External patent database links.
